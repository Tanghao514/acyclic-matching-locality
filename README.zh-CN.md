# 无环匹配：算法与复现材料

作者：唐浩（Hao Tang），吉林大学软件学院。
邮箱：tanghao5524@mails.jlu.edu.cn。

本仓库包含块局部性算法、一次细分图上极大无环匹配的带权优化与精确计数算法、独立枚举验证器和原始实验数据。论文仍为研究稿。

## 快速验证

在仓库根目录运行：

```powershell
python -m pip install -r requirements-validation.txt
python -u validation/run_checks.py
```

建议 Python 3.11。通过时输出 62 项答案验证、76 个结构图验证和 4 个计时基线验证全部通过。不要使用 Python 的 -O 优化选项，否则断言检查会失效。新结果写入 runs/revision，不覆盖 data 下的历史数据。

带权求解器输入是最大度不超过 3 的简单基图；两端关联费用可以分别指定为有符号整数。计数对象是实际匹配，不是根集合。块局部性算法处理一般有限简单无向图。小规模穷举用于核验实现，不能代替一般性数学证明。

旧参数计时脚本需要 Linux 或 WSL；命令、输入格式、运行环境和结果字段见 README.md。原求解器文件未修改；公开运行脚本仅调整目录与运行记录，历史数据保持原样。代码和随附数据采用 MIT 许可证。
